# Sofri um ataque: posso invadir o computador do suspeito?

Uma empresa detecta acesso indevido. Sua primeira obrigação prática é conter o incidente — não “devolver” o ataque.

```python
acesso_indevido = True

if acesso_indevido:
    print("Isolar o sistema afetado")
    print("Revogar acessos comprometidos")
    print("Preservar registros para investigação")
```

1. **Código:** as ações se limitam ao ambiente que a empresa controla.
2. **Resultado:** conter o dano não exige entrar no dispositivo de outra pessoa.
3. **Fundamento:** a legítima defesa exige agressão atual ou iminente e uso moderado dos meios necessários. Ela não dá licença automática para um contra-ataque digital. Invadir dispositivo de uso alheio para obter ou alterar dados sem autorização pode configurar crime.
4. **Decisão do gestor:** definir quem autoriza o isolamento, quem preserva evidências e quando acionar profissionais de segurança e autoridades.

**Papel do advogado:** estabelecer os limites da resposta antes que a equipe transforme a condição de vítima em uma nova infração.

Fonte: [Código Penal, arts. 23, 25 e 154-A](https://presidencia.gov.br/ccivil_03/decreto-lei/del2848compilado.htm).

*Exemplo didático: não identifica atacantes nem executa ações em redes reais.*
